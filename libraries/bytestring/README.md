# ByteString: Fast, Packed Strings of Bytes

This library provides the `Data.ByteString` module.
Byte arrays manipulable as strings.
Providing very time/space-efficient string and IO operations.

@todo: The library also provides `Data.ByteString.Builder` for efficient construction
of `ByteString` values from smaller pieces during binary serialization.

This library is inspired by Haskell's [bytestring package](https://hackage.haskell.org/package/bytestring).
